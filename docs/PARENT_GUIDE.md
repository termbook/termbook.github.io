# Parent and student guide

1. Ask your child's school for the **admission number** and the **access code**.
2. Click **Register**, create an account and verify your email. Choose **I am a parent or student**.
3. Open **My child**, choose the school's state, local government and school, then type the admission number and code. Press **Link child**.
4. After the school **publishes** the term, you see your child's full report card: subject scores and grades, attendance, conduct ratings and comments. You can print it or save it as a PDF.

If it says the code does not match, check the admission number and code with the school. If the school revokes access, you will need a new code.

Only your own child's record is shown to you.
